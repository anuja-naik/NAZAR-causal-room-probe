# E08 — Multi-view optical persistence

**Status:** planned; not run.

## Question

Does a true lens candidate remain geometrically consistent across viewpoints more often than ordinary specular reflections?

## Procedure outline

Observe documented lens and difficult-negative objects from multiple phone viewpoints. Record camera/phone pose and candidate locations. Apply the proposed geometric alignment and track whether each candidate maps to a consistent 3D point or disappears/moves. Include screws, chrome, glass, and water-like negatives where practical.

## Interpretation

Persistence is an additional optical cue, not an absolute lens test. Report object-level counts and failures; do not treat repeated views of the same object as independent examples. No multi-view implementation or result is present here.
