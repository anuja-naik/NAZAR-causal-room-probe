# E02 — Covered-lens null control

**Status:** planned; not run.  
**Priority:** key causal control in the supplied concept.

## Question

When the camera continues transmitting but its lens is physically covered, does the relationship between the measured light challenge and traffic weaken or disappear?

## Procedure outline

1. Establish a baseline with the lens uncovered: run a fresh challenge and record both total traffic and the stimulus-response statistic.
2. Cover the lens without changing the camera’s power/network state; confirm that a traffic stream continues.
3. Run a new fresh challenge and record the same measurements.
4. Repeat under documented conditions, including any interruptions or network-state changes.
5. Compare the stimulus-linked statistic and traffic continuity; preserve all trials.

## Required observations

- traffic volume/frame activity before and during the covered condition;
- measured light trace and timing;
- response statistic, response lag, and surrogate distribution in each condition;
- any camera/network state change caused by handling the device;
- number of trials, exclusions, and deviations.

## Interpretation

The intended observation is **continued traffic with a reduced stimulus-linked relationship**, not merely a traffic outage. This would support the causal explanation for that setup; it would not prove universal camera detection or eliminate other confounds. If traffic stops, timing breaks, or the statistic does not weaken, report that result plainly. This control has not yet been performed.
